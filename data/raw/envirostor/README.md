# DTSC EnviroStor case records

**What to get:** State-level contaminated-site case summaries for Santa Clara County —
this catches former fab sites that never made the federal Superfund list.

**Where:**
- EnviroStor public search: https://www.envirostor.dtsc.ca.gov/public/
  — search by county (Santa Clara) and site type; semiconductor/electronics sites often show
  up under "Cleanup Program Site" or "School" (some sites are near/under redeveloped land)
- Each case has a public case summary page with status, contaminants of concern, and a
  document repository tab with uploaded PDFs (site assessments, cleanup reports).

**How to save:** Save the case summary page text and 1-2 representative PDFs per site into
this folder. Keep original filenames or rename clearly, e.g. `sitename_envirostor_summary.txt`.

**Roughly how many:** 6-10 sites is a reasonable first pass.
