# Vapor intrusion guidance & mitigation status documents

**What to get:** General guidance documents plus site-specific vapor mitigation status reports.
This is what lets the system answer the human-impact question ("is this site's vapor risk
being actively managed?") rather than just regurgitating regulatory status codes.

**Where:**
- EPA vapor intrusion guidance: https://www.epa.gov/vaporintrusion/technical-guidance-vapor-intrusion
- DTSC vapor intrusion guidance: https://dtsc.ca.gov/vapor-intrusion/
- Site-specific vapor mitigation system status updates are often filed within the same
  EnviroStor/GeoTracker case documents you already pulled — if you spot a vapor-mitigation-
  specific PDF while browsing those, drop a copy here too so it's easy to find during chunking.

**How to save:** `.pdf` or `.txt`, descriptive filenames.

**Roughly how many:** 3-5 general guidance docs plus whatever site-specific ones you find
during the EnviroStor/GeoTracker pass — this folder can be the smallest of the four.
