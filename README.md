# Semiconductor_Risk_Q-A
Silicon Valley Semiconductor Contamination & Vapor-Intrusion Risk Q&A — A locally-run retrieval-augmented generation (RAG) system that answers questions about semiconductor-linked groundwater contamination and vapor intrusion risk in Santa Clara County, grounded in EPA Superfund, DTSC EnviroStor, and RWQCB GeoTracker regulatory records. Built an end-to-end pipeline (document parsing, chunking, embedding, local vector search, and generation via a locally-hosted LLM) and a hand-written evaluation set to measure retrieval accuracy and answer correctness before and after tuning. Entirely local — no cloud dependencies.
